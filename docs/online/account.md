# Your account

An online account keeps saved searches and review projects together. The locally installed Community edition does not require a PaperSeek account.

## Create an account

1. Open the avatar menu and choose the account entry.
2. Enter your email address in the registration form.
3. Enter the verification code from the email.
4. Set and confirm a password, then continue.

Use at least eight characters. Follow any additional password requirements displayed by the form. The verification step must complete before a password can be saved.

## Sign in

Use an existing email and password, an email code, or one of the account OAuth buttons offered on the page. OAuth signs you in to PaperSeek; it does not authorize model inference with that provider.

If you use more than one sign-in method, check the account email and ID before continuing work. Do not assume that two different email addresses share history.

## Account information

Open the avatar menu to view the current account and service allowance. The account ID can be revealed with the eye button and copied for support. It is not an API credential.

The account card may briefly show loading placeholders while session and allowance information is fetched. Wait for the current state before interpreting an empty allowance as zero.

## Email or password problems

- Check spam and the spelling of your email address.
- Use the most recent code; a newly requested code can supersede an older one.
- If the verification session expires during password setup, restart verification.
- If you cannot remember your password, choose **Use an email code instead** on the sign-in form. Signing in with a code does not change the existing password.
- If saving the password fails, preserve the visible error and approximate time, then retry through the account flow. Never send your password or verification code in an issue.

A service error during registration does not justify creating several duplicate accounts. See [Troubleshooting](../reference/troubleshooting.md).
