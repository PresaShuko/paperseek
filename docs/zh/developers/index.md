# 开发者

在自己的工具和 Agent 中运行 PaperSeek，或参与项目贡献。

## 集成

| 入口 | 适用场景 |
| --- | --- |
| [Agent Skill](skill.md) | 你的 Agent 可以执行本地命令，需要安装和使用 PaperSeek 的指引 |
| [MCP](mcp.md) | 你的助手使用结构化工具启动、查看、取消和导出检索 |
| [HTTP API](api.md) | 你在运行中的 PaperSeek 服务之上构建应用 |
| [命令行](cli.md) | 你运维本地安装或用脚本操作 |
