# 账户与登录

在线账户保存你的检索、计量分析、综述、已保存的密钥和积分。自行安装的社区版不需要 PaperSeek 账户。

## 注册账户

1. 点击侧栏左下角的 **未登录**，再选择 **注册账户**。
2. 输入邮箱，发送验证码。
3. 输入邮件中的六位验证码。
4. 设置并确认密码。

密码至少八位；如表单显示其他要求，以界面提示为准。

## 登录

可以用邮箱和密码、邮箱验证码，或页面提供的 GitHub、Hugging Face、ModelScope 登录。第三方登录只用于登录 PaperSeek，不代表授权 PaperSeek 使用该平台的模型。

使用多种登录方式时，请先在 **设置 › 用户** 中核对邮箱和账户 ID。两个不同邮箱的历史并不共享。

## 设置 › 用户

从账户菜单的 **账户与积分** 或 **设置** 进入。

- **账户**：显示邮箱和账户 ID。ID 默认隐藏，联系支持时可点 **显示** 或 **复制**。账户 ID 不是 API 密钥。
- **积分**：显示今日剩余积分、恢复时间和各项任务的消耗，详见[积分](index.md#积分)。
- **登录方式**：关联或解除关联 GitHub、Hugging Face、ModelScope；没有密码的账户可在这里设置密码。解除关联不会删除历史。
- **数据管理**：
  - **清空密钥**：删除账户中保存的全部模型连接和数据源密钥，需输入「确认清空密钥」确认。已提交的任务不受影响。
  - **清空历史**：删除全部检索、计量分析和综述及其导出文件，需输入「清空」确认。正在运行的任务会先被停止，积分扣费记录会保留。此操作无法撤销。

退出登录后，已经在运行的任务仍会继续。

## 收不到邮件或密码操作失败

- 检查垃圾邮件和邮箱拼写。
- 使用最新收到的验证码；重新申请可能使旧验证码失效。
- 忘记密码时，在登录对话框中选择 **邮箱验证码**。用验证码登录不会更改原密码。
- 保存密码失败时，记下页面错误和大致时间后重试。不要把密码或验证码发给任何人，包括客服。

注册时遇到临时错误，无需重复创建多个账户。更多排查见[常见问题](../reference/troubleshooting.md)。
