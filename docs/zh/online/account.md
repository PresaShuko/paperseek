# 账户与登录

在线账户用于保存检索历史和综述项目。本地安装的社区版不需要 PaperSeek 账户。

## 创建账户

1. 点击导航栏圆形头像，打开账户入口。
2. 在注册表单中输入邮箱。
3. 输入邮件中的验证码。
4. 设置密码、再次确认，然后继续。

密码至少八位；如表单显示其他要求，以界面提示为准。完成邮箱验证后才能保存密码。

## 登录已有账户

可以使用邮箱与密码、邮箱验证码，或页面提供的账户 OAuth 按钮。OAuth 用于登录 PaperSeek，不代表授权使用该提供方的模型推理服务。

使用多种登录方式时，先核对邮箱与账户 ID；两个不同邮箱不一定对应相同历史。

## 查看账户信息

点击头像查看当前账户与服务额度。账户 ID 可通过小眼睛显示或隐藏，也可以一键复制，方便反馈问题。ID 不是 API 密钥。

会话和额度请求期间，卡片会显示加载占位。请等加载完成后再判断额度，不要把尚未加载的空白理解为零。

## 收不到邮件或密码操作失败

- 检查垃圾邮件和邮箱拼写。
- 使用最新收到的验证码；重新申请可能使旧验证码失效。
- 设置密码期间会话过期时，重新验证邮箱。
- 已有账户忘记密码时，在登录表单选择邮箱验证码登录。使用验证码登录不会更改原密码。
- 保存密码失败时，记录页面错误和大致时间，通过账户流程重试。反馈时不要提供密码或验证码。

遇到注册服务错误，无需重复创建多个账户。更多排查见[常见问题](../reference/troubleshooting.md)。
