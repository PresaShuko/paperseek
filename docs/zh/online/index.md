# 在线使用 PaperSeek

打开 [PaperSeek](https://paperseek.app/)，即可在浏览器中开始研究。在线版与社区版共用检索流程、结果、文献计量、引用图谱和实验性综述工作区。PaperSeek 在线版目前处于公测期。

## 两种运行方式

随时可在左下角的账户菜单，或 **设置 › 模型 API** 中切换。

| | PaperSeek 服务 | 自带密钥 |
| --- | --- | --- |
| 模型 | 由 PaperSeek 提供，从列表选择 | 你保存的模型连接 |
| 密钥 | 无需密钥 | 在设置中保存到账户 |
| 积分 | 消耗每日积分 | 不消耗积分 |
| 账户 | 需要登录 | 保存历史需要登录；未登录可做临时检索 |

模型密钥与数据源密钥是两套凭据。模型 API 密钥不能代替文献数据库的访问凭据。

## 使用 PaperSeek 服务

1. 登录。默认即为 PaperSeek 服务。
2. 填写研究问题，选择数据源和检索预算。
3. 开始检索。表单底部会显示本次消耗的积分和今日剩余积分。

检索和写作使用 **Auto**，由 PaperSeek 为每类任务选用合适的内置模型，目前没有其他选项。初排序在 **设置 › 模型 API** 中设置。可用数据源以应用中显示的为准。

## 积分

公测期间，每个账户每天获得 **20 积分**，免费使用。只有 PaperSeek 服务消耗积分：

| 任务 | 积分 |
| --- | --- |
| 文献检索 | 1 |
| 文献计量 | 1 |
| 文献综述 | 一整篇 5 |

积分在任务开始时扣除。一篇综述只扣一次，由它的第一个写作任务扣除；同一篇综述之后重新生成大纲、写作正文、重写章节都不再扣。任务失败或取消会退回积分；带警告完成的任务不退回。

剩余积分显示在侧栏和 **设置 › 用户** 中，并注明每日恢复时间。公测期间如需更大用量，请发邮件至 [support@paperseek.app](mailto:support@paperseek.app)，在邮件正文中提供您的账户 ID（可在设置 › 用户中复制）、所在单位和用途。我们将尽快为您扩充每日积分。

## 使用自带密钥

1. 在账户菜单中选择 **自带密钥**。
2. 在 **设置 › 模型 API** 中点击**添加连接**，填写模型信息和密钥后点击**保存**（参见[模型与排序](../guide/models.md)）。
3. 在**设置 › 数据源**中，点击来源对应的**配置**或**配置密钥**，填写并保存密钥。自带密钥模式下，可以使用密钥的数据源（包括 OpenAlex、PubMed、Semantic Scholar）都必须提供密钥；arXiv、Crossref、PaperHub 无需密钥，可直接使用。

密钥加密保存在 PaperSeek 服务器，只用于你自己的任务，保存后不再显示，页面只显示末 4 位。自带密钥的任务不消耗积分；上游费用和速率限制由你自己的服务商账户承担。

在线版只接受公网模型接口；localhost、`127.0.0.1`、内网地址等非公开目标会被拒绝。如需连接自己的电脑或局域网中的模型，请运行[社区版](../self-hosting/index.md)。

## 不登录检索

未登录时可以做一次临时检索：在检索表单中选择服务商和模型，直接填写模型密钥（数据源需要时也填写数据源密钥）。密钥只用于本次检索，不会保存，也不会写入浏览器。

临时检索保存在服务器内存中。有效期内可以刷新当前标签页恢复，但不会进入历史；关闭标签页、过期或服务重启后可能无法再查看。文献计量、综述、历史和设置需要登录。需要保留结果时，请**先登录再检索**；之后登录不会导入临时检索。

## 任务排队

站点会限制同时执行的任务数。排队时页面显示前方等待数量，轮到后自动开始，无需重复提交。等待中可以取消排队，已扣的积分会退回。
