# 在线使用 PaperSeek

打开 [PaperSeek](https://paperseek.app/)，即可在浏览器中检索。在线版与社区版共用检索流程、结果、文献计量、引用图谱和实验性综述工作区。PaperSeek 在线版目前处于公测期。

初次使用？[在线完成第一次检索](../get-started/online.md)。

## 两种运行方式

随时可在侧栏底部的账户菜单，或 **设置 › 模型服务** 中切换。

| | PaperSeek 服务 | 自带密钥 |
| --- | --- | --- |
| 模型 | 由 PaperSeek 提供，从列表选择 | 你保存的模型连接 |
| 密钥 | 无需密钥 | 在设置中保存到账户 |
| 积分 | 消耗每日积分 | 不消耗积分 |
| 账户 | 需要登录 | 保存历史需要登录；未登录可做临时检索 |

模型密钥与数据源密钥是两套凭据。模型 API 密钥不能代替文献数据库的访问凭据。

- [服务与积分](credits.md) — 任务消耗、退回和每日恢复。
- [自带密钥](byok.md) — 使用自己的模型和数据源密钥。
- [数据与隐私](privacy.md) — 密钥如何保存，以及如何不登录检索。
- [账户与登录](account.md) — 登录方式和账户设置。

## 任务排队

站点会限制同时执行的任务数。排队时页面显示前方等待数量，轮到后自动开始，无需重复提交。等待中可以退出排队，已扣的积分会退回。
