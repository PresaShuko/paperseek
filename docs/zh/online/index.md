# 在线使用 PaperSeek

打开 [PaperSeek](https://paperseek.app/)，即可在浏览器中开始研究。在线版与社区版共用检索流程、结果、引用图谱和实验性综述工作区。

## 选择使用模式

在导航栏的模式下拉菜单中切换。

| | PaperSeek 服务 | Bring Your Own Key |
| --- | --- | --- |
| 模型来源 | 由站点提供 | 使用自己的模型 API |
| 检索配置 | 数据源、领域、预算、模型与初排序方式 | 社区版的模型与检索配置 |
| 模型连接 | 从列表选择模型 | 配置提供商、协议、地址和 Key |
| 账户 | 需要登录 | 临时检索可免登录 |
| 保存历史与综述 | 登录后可用 | 登录后可用 |

数据源访问与模型调用是两套凭据。模型 Key 不能代替文献数据库的访问凭据。

## 使用 PaperSeek 服务

1. 登录，选择 **PaperSeek 服务**。
2. 选择数据源，必要时限制研究领域。
3. 选择模型与检索预算。
4. 输入研究问题并开始检索。

初排序默认使用本地融合，也可选择界面提供的 Embedding + Rerank 或 System One。连接地址和密钥由站点管理。综述写作同样只需选择模型。

可选模型、数据源和账户额度以应用中显示的内容为准，它们可能随站点配置调整。

## 使用 Bring Your Own Key

选择 **Bring Your Own Key**，按[模型与排序](../guide/models.md)配置连接。上游请求由服务器使用提交的凭据执行。

在线 BYOK 只接受公共模型接口；localhost、`127.0.0.1`、内网地址等非公开目标会被拒绝。如需连接自己的电脑或局域网模型，请运行[社区版](../self-hosting/index.md)。

匿名检索不保存账户历史。临时结果可能在过期或服务重启后丢失。需要保留结果或撰写综述时，请**先登录再检索**；之后登录不会自动导入匿名任务。

## 任务排队

站点会限制同时执行的任务数量。排队时，页面显示等待状态与队列位置，有空位后自动开始。重新打开已有的持久化任务不会另建一份任务。

等待中可以取消。队列已满或等待超时后，需要稍后重试。任务已在排队或执行时，无需反复提交相同问题。

## 额度与上游费用

账户界面显示服务额度。服务检索成功完成时计入使用量，包含带警告完成的任务；失败或取消的检索不计为成功检索。托管写作使用独立额度。

BYOK 模型费用由自己的提供方账户承担。上游余额、速率限制和 PaperSeek 服务额度分别计算。
