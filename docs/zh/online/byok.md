# 自带密钥

用自己的模型和数据源密钥运行任务，替代 PaperSeek 服务。使用自带密钥的任务不消耗积分；上游费用和速率限制由你自己的服务商账户承担。

## 配置密钥

1. 在侧栏底部的账户菜单中选择 **自带密钥**。
2. 在 **设置 › 模型服务** 中点击**添加连接**，填写模型信息和密钥，然后点击**保存**（参见[模型与排序](../guide/models.md)）。
3. 在 **设置 › 数据源** 中，点击来源对应的**配置**（或**配置密钥**），保存密钥。自带密钥模式下，所有支持密钥的数据源都必须提供密钥，包括 OpenAlex、PubMed 和 Semantic Scholar；arXiv、Crossref 和 PaperHub 无需密钥。

模型密钥与数据源密钥是两套凭据。模型 API 密钥不能代替文献数据库的访问凭据。

## 仅限公网接口

在线版只接受公网模型接口。localhost、`127.0.0.1`、内网地址等非公开目标会被拦截。要使用自己电脑或网络中的模型，请运行[社区版](../self-hosting/index.md)。
