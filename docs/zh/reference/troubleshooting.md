# 常见问题

先看任务状态和具体错误。上游缓慢、任务排队与浏览器断线，需要不同处理方式。

## 检索一直在等待

先区分**排队中**与**执行中**。检索式改写、数据源请求、引用扩展、模型评分都会耗时。更高预算允许更多工作，但不保证一定得到更多有用文献。

页面断线时，先重新打开已保存的任务查看状态，不要立即重复提交。在线匿名结果为临时保存，见[在线版指南](../online/index.md)。

## 出现 HTTP 401、403、404 或 429

| 错误 | 检查方向 |
| --- | --- |
| 401 / 403 | Key 是否正确、账户权限、所选模型是否可用 |
| 404 | API 基础地址、协议、路由、模型或任务资源是否存在 |
| 429 | 上游速率限制，或结构化错误中的余额不足 |
| 连接失败 / 超时 | 网络可达性与提供方服务状态 |

OpenAlex 任务中出现 404，不等于一定由 OpenAlex 返回；任务中还会调用模型和应用接口。请记录阶段、安全错误码、任务 ID 与时间。

PaperSeek 服务额度与上游提供方余额是两套限制，调整其中一个不会改变另一个。

## 在线版拒绝了模型地址

在线 BYOK 会拦截本机、内网等非公开地址。请使用公共接口，或在社区版中连接自己电脑上的模型。地址可达之外，还必须支持所选 API 协议。

## 没有结果、缺摘要，或各处数量不同

尝试细化或适当放宽问题、去掉过严领域限制，或换用更合适的数据源。数据源命中数量不等于已下载数量，候选数量也不等于最终排序结果数。

摘要、引用数、PDF 等缺失可能来自原始记录。PaperSeek 不会独立从其他来源补全文献摘要。

## 引用图谱为空

确认使用了支持引用扩展的数据源，并启用了扩展。即便开启，来源也可能在当前预算内没有返回可用引用关系。

## 综述大纲或正文生成失败

综述为实验性功能，取决于选中文献证据和模型状态。优先选择摘要完整的文献，查看项目及任务当前状态，解决上游问题后再重试失败环节，避免重复创建相同项目。

更长正文需要模型输出更多内容；大纲成功不代表下一次写作请求一定成功。重新生成前，保留手工修改并检查版本。

## 本地服务无法启动

执行 `paperseek doctor --json`，检查 Python 3.12+、数据库路径、写权限、端口冲突和模型配置。执行日志请在启动终端或服务管理器中查看；网页聚焦任务状态，不显示原始黑框日志。

独立启动 API 与 worker 时，确认它们指向同一个数据库。

## 如何反馈问题

在 [GitHub Issues](https://github.com/MingfengHong/paperseek/issues) 提供：

- 安装版本或在线模式、浏览器及系统、复现步骤。
- 数据源、模型协议、排序方式与预算。
- 期望行为、实际错误、适当的任务 ID 和大致时间。
- 不含敏感信息的最小示例，必要时附裁剪后的截图。

删除 Key、密码、验证码、Cookie、私人研究问题和身份信息。安全漏洞请按仓库[安全反馈流程](https://github.com/MingfengHong/paperseek/blob/main/SECURITY.md)处理。
