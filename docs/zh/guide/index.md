# 认识 PaperSeek

PaperSeek 是一个开源文献研究工作区。从自然语言问题开始，寻找相关文献、探索引用联系，再将证据整理成综述。

它将大模型与学术数据源结合。你可以查看检索策略与进展，打开原始记录，并导出自己的阅读清单。

## 选择使用方式

| | 社区版 | 在线版 |
| --- | --- | --- |
| 开始使用 | 安装到自己的设备或服务器 | 打开 [paperseek.app](https://paperseek.app/) |
| 模型 | 自行配置模型服务 | PaperSeek 服务或自带密钥 |
| 历史 | 本地数据库与文件 | 已登录账户的云端记录 |
| 账户 | 不需要 PaperSeek 账户 | 保存历史、使用综述需要登录 |
| 本地模型地址 | 支持自己部署的本地服务 | 自带密钥只允许公开模型服务地址 |

[安装社区版](quick-start.md) · [使用在线版](../online/index.md)

## 从问题到综述

1. **描述研究问题。** 写清研究对象、关注的关系和必要场景。
2. **检索与调整。** 制定策略，迭代适合数据源的检索式。
3. **阅读文献结果。** 查看摘要、相关性理由、出版信息与原始记录。
4. **探索引用联系。** 使用 OpenAlex 引用扩展，发现初始结果之外的线索。
5. **整理文献综述。** 选择文献、确认大纲，再基于摘要证据生成草稿。

顶部为**文献检索、文献计量、文献综述**三个标签，各有独立的折叠历史侧栏。侧栏底部提供独立设置页与账户菜单，详见[工作区与历史](workspace.md)和[文献计量](bibliometrics.md)。

## 如何理解结果

PaperSeek 帮助发现和整理文献，不保证系统综述意义上的穷尽检索，也不能代替阅读原始论文。相关性得分不是研究质量评分。综述依据可用的摘要和元数据，不会自动获取全文。

数据源、模型、预算和可选排序方式会影响覆盖范围、耗时与接口用量。
