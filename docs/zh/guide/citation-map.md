# 探索引用图谱

查看检索结果周围的研究联系，而不是逐篇浏览孤立的论文。

## 获得图谱

检索前选择 **OpenAlex** 并启用引用扩展，程序会在预算内探索参考文献与施引文献。

任务结束后从检索结果打开**引用证据**，或进入**文献综述 → 引用证据 → 文献关系**。未收集引用数据时，空图谱是正常状态；切换页面不会自动补做扩展。

## 阅读图谱

节点代表论文，箭头从引用他人的论文指向被引用论文。

图例区分结果、种子、前向和后向扩展角色，表示文献如何进入图谱，不是质量分类。

点击节点查看论文和原始链接，网络密集时使用图谱控件调整视图。

## 理解范围

这是有预算限制的探索，不是整个领域的完整引用网络。数据覆盖、标识符缺失和来源更新会影响连接结果。

引用数不是相关性评分，近期的相关文献也可能几乎没有引用。

回到[结果](results.md)页阅读、选择或导出。
