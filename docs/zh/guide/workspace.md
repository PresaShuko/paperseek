# 工作区与历史

顶部固定为**文献检索、文献计量、文献综述**三个标签。本次会话中切换模块，会返回该模块上次停留的页面。

| 模块 | 子功能 | 历史记录对应对象 |
| --- | --- | --- |
| 文献检索 | 检索设置、运行过程、检索结果 | 一次检索任务 |
| 文献计量 | 概览、关键词、文献关系、数据质量 | 一份独立候选集分析 |
| 文献综述 | 文献、大纲、正文、引用证据 | 一份可编辑综述 |

左侧历史栏只显示当前模块的记录，收起后变为保留新建、历史、设置和账户入口的图标栏，小屏幕改为可关闭的抽屉。侧栏提供新建、搜索、记录操作和管理历史。尚未保存或提交的新草稿不会成为历史记录。

记录可重命名、导出和删除。重命名不改检索问题、综述主题或原始运行参数。删除需要确认，正在运行的任务不能直接删除。

侧栏底部提供独立的**设置**入口和账户菜单。设置页分为**模型与评分、数据源、通用**，可通过 `/settings/models`、`/settings/sources`、`/settings/general` 直接打开；主内容区独立滚动，高级参数按需展开。点击**完成设置**或**返回工作区**回到进入前的页面，检索草稿保留。修改即时用于新检索，无需额外保存；刷新会清空内存中的草稿和密钥。账户菜单提供语言与文档帮助，在线版还提供账户、默认服务模式和登录登出，子菜单标记当前选项。模型与数据源默认值作用于新检索草稿，历史检索保留原配置；综述中的模型设置作用于当前综述，生成期间不能修改。密钥只留在内存，不写入浏览器存储。

引用图谱放在综述的**引用证据 → 文献关系**中。旧图谱与历史直达链接继续可用。

切换模块保留本次浏览器会话中的已加载结果、筛选、勾选和滚动位置。结果缓存保留最近访问的十次检索，刷新后清空这些临时状态。离开未保存的大纲或段落编辑时，会提示继续编辑或放弃修改；刷新前请先保存。

新综述会将可用的来源引用图保存在自身证据中，删除来源检索后仍可查看；没有这份快照的旧综述仍依赖来源记录。文献计量分析始终保存自己的候选集快照。
