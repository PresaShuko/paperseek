# 模型与排序

语言模型负责检索规划与相关性评估，可选初排序帮助选择进入最终模型评分的候选。

## 连接模型

社区版 / BYOK 中选择服务商与模型，再确认 Key、基础地址和协议。预设只是起点，模型必须在服务商处实际可用。

| 协议 | 接口操作 |
| --- | --- |
| OpenAI Chat Completions | `/chat/completions` |
| OpenAI Responses | `/responses` |
| Anthropic Messages | `/v1/messages` |

基础地址应符合协议要求，不要重复拼接请求路径。兼容 Chat Completions 不等于兼容 Responses。

PaperSeek 服务只提供模型下拉菜单，地址和密钥由维护者配置。

## 初排序方式

**默认使用本地融合。**

| 方式 | 行为 | 额外服务 |
| --- | --- | --- |
| 本地融合 | 综合本地词法、哈希语义信号与多路召回排名 | 无需 |
| Embedding + Rerank | 最终候选选择前的外部向量与重排序 | Embedding 和 Rerank API |
| 决策模型 | 使用 System One 协议评估本地融合后的候选 | 兼容决策 API |

本地融合只指初排序，整次检索仍需要语言模型和网络请求。

决策路径最多评估最终 LLM 候选预算两倍的文献，再选最终子集，仍受实际候选数和预算约束。

## 不同版本的设置

**社区版 / BYOK**：可配置模型路由和凭据，写作模型可以与检索模型不同。

**PaperSeek 服务**：选择受支持的检索和写作模型，保留初排序方式选择，地址和密钥留在服务端。

## 本地模型

社区版支持运行设备可连接到的兼容模型服务，包括回环地址。

在线 BYOK 会拒绝回环、内网、链路本地等不安全目的地，以防止 SSRF。`127.0.0.1` 指向在线服务器，不是你的笔记本；本地端点请使用社区版。

## 降级与失败

可选排序失败时，程序可能保留本地顺序并显示警告，不代表外部排序成功。应查看本次记录的配置和执行状态。

鉴权、余额、速率限制、超时和响应格式错误需要不同处理方式，见[常见问题](../reference/troubleshooting.md)。
