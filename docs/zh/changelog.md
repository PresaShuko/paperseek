# 更新日志

从首个演示版本到 PaperSeek 1.0.0-beta1，记录各版本的功能、改进与升级事项。

## 1.0.0-beta1 {#v1-0-0-beta}

PaperSeek 1.0.0-beta1 是一次**完整的架构重构，包含不兼容变更**。本次围绕共享研究应用重建任务执行、前端、存储边界与分发方式，并为已有用户数据提供明确的迁移路径。

### 三个模块与独立历史

- 按 shadcn 视觉风格重新设计工作区：文献检索、文献计量、文献综述位于可折叠侧栏，各模块保留独立历史，账户位于左下角。
- 设置页包含模型 API、数据源、通用和用户数据：可清空已保存的密钥或全部历史，均需输入确认语；清空历史前会先停止正在运行的任务。
- 新增针对实际获取去重候选集的初步计量：原生字段覆盖、关键词共现、受限文献耦合、网络缓存及独立导出；LLM 评分仍为子集。
- 综述整合选文献、大纲、正文和引用证据，新综述保存可用的来源图快照。
- 重命名只改显示标题，不改原查询和执行配置。

此 beta 直接接续 0.2.x。Python 安装包使用规范化版本 `1.0.0b1`，公开版本与容器标签为 `1.0.0-beta1`。文档描述目标版本，实际部署状态另行报告。

### 在线版

- 登录后使用 PaperSeek 服务：内置模型、无需密钥，公测期间每日免费 20 积分。一次检索或计量消耗 1 积分，一篇综述消耗 5 积分，在任务开始时扣除；任务失败或取消会退回。
- 自带密钥：在设置中把模型连接和数据源密钥保存到账户，任务使用你自己的 API，不消耗积分。此模式下，除 arXiv、Crossref、PaperHub 等无需密钥的数据源外，其余数据源（包括 OpenAlex、PubMed、Semantic Scholar）都必须提供密钥。
- 不登录也可以在表单中填写自己的密钥，做一次临时检索。结果只保存在内存中，不会进入历史。

### 按职责重建架构

- 分离 `paperseek_core`、`paperseek_app` 与部署适配层：核心负责召回、检索式迭代、引用扩展、排序及数据源／模型协议；应用层负责提交、执行、持久化与查询；Community 和 Hosted 各自实现部署与存储适配。
- Web、CLI、HTTP API 和 MCP 共用应用层。检索核心不依赖 FastAPI、账户认证、SQLite 或 Supabase。
- 以固定版本的 Community wheel 替代跨仓库源码复制。Hosted 从同一发行物使用共享 Python 实现与 Vue 源码，再装配账户、存储和服务策略。
- 以 Vue 3、TypeScript 和 Vite 重建前端。两端共用研究页面，通过版本化 `/api/v1` 契约通信，并由后端生成 API 类型以校验接口一致性。
- 使用明确的异步工作流、httpx 客户端和 Pydantic 边界模型，清理实验性 Harness 与废弃的运行入口。

### 持久任务、取消与恢复

- 将保存的检索建模为数据库中的任务，统一 worker 租约、顺序事件、检查点与结果产物。社区版可从已提交的兼容检查点恢复中断任务。
- 页面通过任务快照、事件回放和 SSE 恢复已保存的状态；浏览器重连无需重新提交检索。
- 统一取消与执行权校验，阻止失去租约的旧 worker 或取消后迟到的提供方响应提交结果。
- 区分数据源／模型故障与持久化故障：可选召回或排序环节失败时可以提示警告并降级，结果保存失败则不能显示为成功。
- 引入 Alembic 管理的 SQLite 版本迁移和显式迁移命令。社区版使用 SQLite 与本地文件；在线版使用独立的 PostgreSQL 和 Storage 适配。在线匿名 BYOK 保持临时运行，不建立持久研究历史。

社区版可由单个本地服务运行 API 和内嵌 worker，也可显式分开运行；在线版在服务器运行 API 与 worker，前端独立部署。任务恢复遵循各版本策略，浏览器重连与服务器中断任务的重新执行是不同操作。

### 完整的研究工作区

- Vue 3 界面，中英文切换，统一导航和分阶段任务状态。
- 从研究问题出发的检索式迭代、有边界的召回、相关性排序与可查看的检索过程。
- 八个学术数据源集成，各自的领域与访问设置。
- 本地融合、Embedding + Rerank、System One 三种初排序方式。
- 基于 OpenAlex 的引用扩展与交互图谱。
- 历史任务、筛选、选择及完整 CSV/JSON 导出。
- **实验性**摘要综述：可编辑大纲、分节写作、版本、引用和 Markdown、Word、BibTeX 导出。

### 一套应用，多种入口

Web、六命令 CLI、版本化 HTTP API 和独立的同版本 MCP 适配器共用应用服务。社区版将数据保存在本地 SQLite 和文件中；在线产品增加账户、服务模型、排队与隔离存储。

### 升级须知

需要 **Python 3.12+**。旧 Python 导入路径、内部 API、前端接口以及废弃的 CLI／配置入口不再保留。0.2 用户数据与仍有效的环境配置通过显式命令迁移，新运行时使用新配置名称，不再回退读取旧名称。详见[迁移指南](self-hosting/upgrade.md)与[架构说明](contributing.md#architecture)。

检索使用数据源原生摘要与元数据，不再提供独立的跨源摘要或引用数补全配置。

## 0.2.0 {#v0-2-0}

2026 年 7 月 4 日 · 多数据源与多路召回

### 检索与排序

- 扩展数据源，加入 arXiv、Semantic Scholar、PubMed、计算机顶会和 Crossref。
- 支持按数据源生成检索式、识别检索意图，并在多轮检索中使用结果反馈。
- 在 LLM 评分之前加入初排序：综合相关性、影响力或引用数、时效性与本地质量信号，通过 RRF、BM25／词项覆盖和本地 hashing embedding 融合候选文献。
- 可选接入兼容 OpenAI 的 Embedding 与 Reranker 服务。

### 在线账户

- 更新邮箱注册与登录流程，支持 GitHub、ModelScope OAuth。
- 该版本为登录用户提供每日 20 次成功检索额度。

## 0.1.0 {#v0-1-0}

2026 年 6 月 2 日 · 首个演示版本

首个版本建立了从研究问题到文献列表的基本流程：

- 输入中文或英文研究问题，由 LLM 生成查询，并根据数据源结果多轮放宽或收窄检索范围。
- 整理文献元数据，由 LLM 给出相关性评分与简短理由。
- 通过 OpenAlex 扩展引用关系，提供可拖拽、缩放和平移的引用图谱。
- 在网页中搜索、筛选和选择结果，导出 CSV。
- 提供本地网页、命令行、Docker 部署和可选 Agent Skill。
- 支持模型服务商、兼容接口与本地 Ollama。

该版本的发布页仅提供提交历史，没有单独列出功能；以上按 [0.1.0 标签下的 README](https://github.com/MingfengHong/paperseek/blob/v0.1.0/README.md) 整理。
