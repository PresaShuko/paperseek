# Developers

Run PaperSeek inside your own tools and agents, or contribute to the project.

## Integrate

| Entry point | Use it when |
| --- | --- |
| [Agent Skill](skill.md) | Your agent can run local commands and needs guidance on installing and using PaperSeek |
| [MCP](mcp.md) | Your assistant uses structured tools for starting, inspecting, cancelling, and exporting searches |
| [HTTP API](api.md) | You are building an application against the running PaperSeek server |
| [Command line](cli.md) | You operate or script a local installation |
